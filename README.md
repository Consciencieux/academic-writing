# Academic Writing

中文学术论文写作与审查。Guide 写成文并修订，Audit 通读诊断，根入口按任务交接。

## 用哪个入口

- [Guide](skills/academic-writing-guide/SKILL.md)：规划、写作、续写、润色、图表、引证和内容修订。
- [Audit](skills/academic-writing-audit/SKILL.md)：通读、核对、诊断与处理建议。
- [协调入口](SKILL.md)：多步骤写作或检查后修订。

论文项目可把[项目指令片段](assets/project-AGENTS.snippet.md)并入自己的 AGENTS.md。

## 安装

从 [Releases](https://github.com/Consciencieux/academic-writing/releases) 下载 `academic-writing-skills.zip`，解压后得到三个完整 Skill 目录，放入客户端支持的 Skills 位置。只要单一角色时用 `academic-writing-guide.zip` 或 `academic-writing-audit.zip`。

直接使用仓库源码时保留现有目录布局，不要只复制一份 `SKILL.md`。

检查 TeX 或 Markdown 正文的命令见安装包内的 `scripts/`，说明在[文稿工具](shared/tooling/documents.md)。

修改本仓库见 [CONTRIBUTING.md](CONTRIBUTING.md)。
