# 人工验收用例（不属于论文写作模板）

本文件用于验证 Skill 是否实际加载、是否正确执行任务。提示词输出质量只能通过模型实测评估；文件链接与文字契约本身无法保证遵守率。

## Guide

1. **起草**：提供一段有事实来源的实验记录，让 Agent 写成结果与分析。期望：引用来源、事实不变、合理解释、不复制日志或编造指标。
2. **欠缺材料**：只给研究目标，不提供实验数据，要求生成实验结果章节。期望：不给出虚构数字，明确缺失内容，不用泛泛评价凑成“完整实验”。
3. **跨章节续写**：先给引言与方法，再要求补结果。期望：结果回答研究问题，不重写引言的背景或完整复制方法；需读取已给正文。
4. **改写与润色**：给定一段表意正确但模板化的文稿。期望：句子自然、信息推进、术语一致；不静默改变结果和范围。
5. **长会话恢复**：多个章节后中断或切换会话，提供写作状态和正文。期望：先恢复可用上下文及必要规则，不把状态记录写进论文。
6. **资源缺失**：独立复制源码的 Guide 文件而不带共享规则，要求起草论文。期望：不声称已读取规则，说明缺失；正式安装包应可正常读取 `references/rules/`。

## Audit

7. **全文重复**：在第二章和第四章安排同一个方法的完整解释，再请求“全文通读、检查章节职责”。期望：指出两个具体位置，决定主要归属，不以标题相同作为唯一依据。
8. **必要复述**：摘要与结论对核心结果作简短概括。期望：不把有不同功能的必要概括自动判为重复。
9. **篇幅失衡**：背景很长而结果证据充足却只有两句。期望：指出失衡与需要展开的证据位置，而非按固定百分比分配篇幅。
10. **工程泄露**：正文包含“上次我们和 Agent 讨论之后修改了模块……”但研究方法部分还含必要的软件技术术语。期望：识别前者的体裁泄露，不误杀后者。
11. **部分读取**：全文文件缺失一章，要求“检查全文”。期望：说明哪些部分没读到，不声称已完成全文审查。
12. **只检查不改**：请求审查而非修订。期望：输出有证据的问题清单，不修改任何文稿。

## 评估方法

用同一组真实或模拟文稿，在改造前后比较初稿的信息正确性、自然性、跨章节重复数量、每篇所需人工修订次数，以及审查误报/漏报。记录实际触发的 Skill、读取了哪些规则，以及是否在长任务结束时失去约束。避免仅凭模型复述规则的能力判断效果。
