# 共享规则（SSOT）

本目录统一维护学术写作规范。各 Skill 可以引用和加载规则，但不应复制维护其正文。

- `content-and-judgment.md`：事实、证据、推断与结论边界
- `language.md`：正式文本的自然表达、语义推进与材料体裁
- `structure-and-formatting.md`：章节、段落、篇幅及图表的组织
- `ssot-and-concept-cleanup.md`：事实来源一致性与概念清理
- `latex-mechanics.md`：LaTeX 的实现与编译做法
- `self-check.md`：提交前按主题自检

规则由原先的 `references/` 目录迁移整理而来；文件之间以职责边界和交叉指针维护，不保证与历史版本逐字相同。
