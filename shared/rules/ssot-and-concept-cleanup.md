# 单一事实来源与已移除概念清理

两部分：一是「同一事实只维护一处」（SSOT），二是「删除就是彻底删除」（概念清理）。两者都服务于同一目标：让文稿只描述当前状态，并且改一个事实只需要改一个地方。

## 一、单一事实来源（SSOT）

核心原则：同一事实只有一个权威来源。

其他文档可以引用它、解释它、自动生成它、在必要时重复表述结论，但不得独立手工维护同一个事实的第二份副本。

> 可以重复表达，不应重复维护。

### 哪些内容应有权威来源

以下内容原则上不应在多个文件中手工维护：参数、阈值、配置项；版本号、日期、状态；接口、字段、数据结构；规则、规范、流程定义；实验数据、统计结果、指标；表格中的可变数据；参考文献及其元数据。

权威来源应放在最适合定义该事实的位置：

| 事实类型 | 权威来源 |
| --- | --- |
| 参数与数据 | 配置／数据文件 |
| 规则与定义 | 规范文档 |
| 实际实现行为 | 代码 |
| 参考文献 | `.bib` |

### LaTeX 正文中的四种承接方式

| 方式 | 用法 |
| --- | --- |
| 引用 | 权威来源已有定义时优先引用，而不是重新定义 |
| 复用 | 同一项目内多处出现同一个值时，使用宏、`\input` 等方式复用 |
| 自动生成 | 实验结果、统计数据、大型表格优先由数据或脚本生成 LaTeX |
| 独立表述 | 为行文需要可以重新解释同一事实，但不得因此产生新的可独立修改的数据源 |

### 什么情况属于治理问题

```text
docs/spec.md     → 定义阈值 0.85
paper/method.tex → 手工写死 0.85
README.md        → 手工写死 0.85
```

问题不在于文字重复，而在于：修改 0.85 时，需要人工记住并修改多个位置。

不要用「以后注意同步」解决这类问题，应改成：

```text
权威来源 → 引用／复用／自动生成 → 正文
```

### 修改文档时的检查

新增事实前先确认：

1. 该事实是否已经存在。
2. 哪个文件应作为权威来源。
3. 新内容是否会产生第二个维护点。
4. 能否改为引用、复用或自动生成。

发现重复维护时，应优先消除重复，而不是继续要求人工同步。

### 对 Agent 的要求

如果发现同一事实存在多个来源、正文手工复制了规范内容、数据已经有来源但表格再次手填、版本与参数存在多个维护点，应指出这些位置，并判断：哪个应作为权威来源；哪些应删除；哪些应改为引用；哪些应改为自动生成。

不应为了完成当前任务而继续复制已有事实。

### 判断标准

修改一个事实时问自己：**如果这个事实明天发生变化，我需要手动修改几个地方？** 理想答案是**一个**。

高频变化或高风险事实应逐步采用「唯一事实来源 → 引用／复用／自动生成 → LaTeX 正文」，必要时通过 CI 检查生成文件是否过期、关键参数是否一致。

## 二、已移除概念清理

目的：被移除的概念、组件、接口、文件或方案，应从项目上下文中完全消失。

移除一个概念意味着它在当前项目状态中不再存在。除项目历史规则明确要求外，不保留描述其曾经存在过的引用。

### 规则

用户要求移除某个概念时，把移除当作**完全语义删除**，而不是替换说明。移除后：

- 项目只描述当前实现。
- 文档、代码注释、示例、测试、指令都不得提及被移除的概念。

### 禁止的写法

不得写：

- A 已被移除
- A 已不再使用
- A 已被 B 取代
- 此前系统使用 A
- 若出现 A，请删除
- 不要使用 A
- 旧的 A 方案
- 与 A 不同，当前实现使用 B

除非用户明确要求迁移文档或历史记录。

### 执行流程

1. **发现**。修改前搜索全部引用：文件名、源码、注释、文档、配置、测试、示例、提示词、生成物，形成完整引用清单。
2. **移除**。删除或改写所有引用，不把直接引用替换成否定式引用。

   ```text
   差：项目已不再使用 A。
   好：项目使用 B。
   ```

3. **验证**。修改后再次搜索。只有活动引用、解释性引用、警告性文字都已消失，才算完成。用仓库级搜索验证，例如：

   ```bash
   grep -R "removed_concept" .
   ```

### 例外

仅在以下情形可以保留：用户明确要求迁移文档；需要保留历史变更记录；需要兼容性文档。这些情形应把引用隔离在合适的历史章节中。

### Agent 行为

不要假设提及被移除的概念是有帮助的，避免解释「移除了什么」，优先描述当前状态而不是变更历史。

目标：新的贡献者阅读仓库时，不应遇到被移除的概念，除非历史上下文是被有意保留的。
