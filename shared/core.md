# 成文目标

先由研究问题、材料和推导形成判断，再把已经成立的内容写成正文。结论的强度与证据匹配；证据充分时，直接作出明确判断。

用完整中文句子交代对象、动作和关系。抽象术语落到具体含义，句段随论证推进。重要条件进入对应命题，限制只保留会改变解释或使用的信息。

正文承载研究事实、解释和结论。计算过程中的待办、资料访问状态与工作安排留在工作记录；影响论文结论的缺口在相关论证处交代。

连续论证使用段落，检索与比较使用行列语义清楚的表格。普通正文采用常规字重，标题、表头、引语及规定格式按其用途呈现。

修订完成后回读受影响的完整句段，处理事实、指代、重复和版式。概念删除按其名称、别名及依赖关系清理授权范围，并复查关联文件与生成物。
