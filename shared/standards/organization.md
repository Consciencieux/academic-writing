# 论证组织与篇幅

约束信息放在哪里、各部分承担什么任务。具体规划方法由 Guide 提供。

<a id="org-01"></a>
## ORG-01 主线与文种【默认原则】
结构沿研究问题、证据和读者理解的需要展开。章节名称、顺序及固定栏目以目标文种或明确要求为准；研究报告、综述、理论论文、系统论文不强制套用同一实验型目录。

正文应让读者理解问题、方法或论证依据与所得结论。两个章节回答同一主要问题且没有独立功能时，应重新分工；不是标题相似就应合并。

<a id="org-02"></a>
## ORG-02 主表达位置与功能性重复【条件要求】
一个实质论点或完整定义有主要展开位置。其他位置可以承担引入、概括、应用、比较或回查功能。摘要、引言、结论的必要概括，以及不同章节必要的符号提醒，不是重复维护事实。

认定冗余须指出两处承担相同任务、没有新增作用的内容。认定散落须说明分散如何妨碍理解，不能以“同一词出现在多章”定罪。比较原段落及上下文，不能只比目录或关键词。

<a id="org-03"></a>
## ORG-03 篇幅与预算【条件要求】
在总字数、页数及图表限制内，优先给关键方法、证据、推导与解释足够空间。篇幅按任务难度、信息量和重要性安排，不均分，不套固定百分比。

区分真实预算与估算。中文字符数、英文词数、LaTeX 源码行数、渲染页数不是同一指标。背景挤占核心论证、空内容扩写和关键证据过短都应处理。版式只能在不破坏必要内容时调整。

<a id="org-04"></a>
## ORG-04 段落与信息连续性【默认原则】
段落有主要任务，句间关系应可理解。衔接、解释与适当重述可以不增加新事实，却提供理解功能；不要求每句都引入一个新数据点。

删除测试同时考虑事实、推理、指代、可读性与导航的损失，不能只数新事实。段落可长可短，允许必要的主题句和过渡；删除没有作用的语义回环与多层总结。

<a id="org-05"></a>
## ORG-05 标题、列表与空栏目【默认原则】
标题指向讨论对象或发现；固定栏目允许“引言、方法、结果、讨论”等常规标题。标题层级由检索需要决定，只有一句而无独立任务的小节可并入正文。

列表用于真正并列的步骤、条件、选项或检查项，不把连续论证机械拆行。无必要内容的栏目删除；任务强制保留的栏目使用简短真实状态，不填造内容。

<a id="org-06"></a>
## ORG-06 交叉引用与读者定位【条件要求】
引用补充定位，不替代当前句子的主要信息；正文应提供理解主论证所需内容。图表、附录和公式的回指按读者需要与投稿要求使用，不全面禁止“见图”或章节号。

一个流程已由图完整呈现时，正文解释原因、条件、结果或选择依据。必要引用与必要概括不能为了“去重复”一并删掉。

<a id="org-07"></a>
## ORG-07 层级与版式【默认原则】
内容关系稳定后调整字号、间距、分页、图幅和表宽。有限而一致的层级帮助阅读；视觉强调不代替证据或制造专业感。目标模板的标题、表头与规定强调正常保留。

为避免留白而增加空话，或为塞进页面删掉关键限定、缩至难读，均不合适。没有渲染实际成品时，不宣称分页或溢出检查已通过。
