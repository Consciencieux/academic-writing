# 文章组织

<a id="org-01"></a>
## ORG-01 主线与章节职责

按研究问题和读者的理解顺序组织材料，让读者找到讨论对象、核心主张、依据及结论。内容正确、关系清楚、阅读自然、检索方便，依次决定结构与版式。

每个章节承担明确任务，交代本章独有的信息及其与前后章的依赖。主要回答同一问题而缺少独立功能的章节，合并或重新分工。小问题放在合适段落，复杂问题按真实内容展开。

文种和目标格式决定必要栏目。经验研究、理论论文、系统论文、综述及课程报告各按实际任务组织；“背景—意义—目标—内容—创新—总结”只在相应内容确实存在时采用。

<a id="org-02"></a>
## ORG-02 主表达位置与跨章重复

一个实质论点、定义或方法有主要展开位置。其他位置承担引入、概括、应用、比较或回查功能。摘要帮助快速了解，引言建立问题，结论回答研究问题；这些功能可以使用同一事实。

对两处候选重复，回读原段及上下文，比较它们实际完成的任务。相同任务被完整做两次时合并；一个完整论点散落多处妨碍理解时，确定集中展开位置。

典型冗余是“标题说一次—正文换词说一次—小结再说一次”，以及任务相同的“本节结论／核心结论／总体判断／最终总结”。段落内部的信息推进见[PROSE-01](prose.md#prose-01)，图表与文字的分工见[VIS-01](visuals.md#vis-01)。

<a id="org-03"></a>
## ORG-03 篇幅与信息量

篇幅按重要性、证据量和解释难度分配。关键方法、证据、推导与解释得到充分空间，信息少的部分简写。章节、案例和模块允许有不同数量的段落、小标题与小结。

两类失衡需要处理：内容单薄却靠背景、意义、重复和小结占据大量篇幅；核心证据或方法只用一两句带过。前者压缩或重组，后者补足有材料支持的解释。各部分的结构差异应反映内容差异。

按用户或目标格式确定总预算及计数范围。中文字符数、英文词数、图幅和渲染页数分别计量；给估算时说明口径，最终页数查看成品。预算依据当前论证分配，而非均分或套用固定百分比。

<a id="org-04"></a>
## ORG-04 论文题名、章节标题与层级

先确定论文或章节实际回答的问题，再以自然、准确的中文命名。标题保留主要研究对象、问题或关系，以及辨认研究范围必需的信息。材料中出现的关键词只帮助理解，不能直接拼成题名；论据、次要变量、实现细节和评价词留在相应正文。

**论文题名。** 标识全文实际完成的研究。经验研究根据对象、变量关系及必要的样本或条件命名；理论研究根据主要问题、对象或命题命名；系统研究根据实际研究的技术问题与方法命名；综述说明综述对象和范围。只保留区分该研究必需的方法或限定，不把所有任务、贡献和结果拼进主副标题。判断型题名按[EVID-02](evidence.md#evid-02)保持结论强度；范围有限的实验不得在题名中扩成普遍规律。外部要求明确时使用规定的文种、范围与题名格式。

**章节与小节。** 标识本节独有的定义、方法、比较、推导、结果或讨论任务。引言、方法、结果、讨论、结论等正常栏目按论文类型与目标模板保留。上级标题已明确的对象可以省略，下级仍需能区分相邻小节。不同消融条件、方法或样本确实并列时，可使用自然的平行名称；不为整齐强凑结构，也不为变化破坏对应关系。

术语使用领域中明确、自然的名称，保留数学对象、必要变量、完整技术名及决定范围的条件。正文已经给出具体对象时，标题直接命名；不要为显得学术添加“机制、路径、价值”等空泛词，也不要为显得通俗改成含混的聊天句。问题式标题须对应真实研究问题或具体检索需要；普通介绍可直接命名对象。

**长度与信息取舍。** 普通中文小标题可优先尝试 4–12 个汉字，13–18 个字在必要信息明确时正常使用；超过 18 个字时检查是否包含重复概括、多个重心或次要关键词。这组范围只作编辑提示，不设最低字数、硬上限或自动违规判据。“引言”“方法”等短栏目正常保留，必要术语与研究范围不能为凑字数删去。论文主标题、外语题名、公式及模板要求不套用小标题字数参考；遵守用户或目标期刊明确的实际限制。

标题层级由独立信息与检索需要决定。只有一两句且没有独立任务的小节并入相邻正文；仅获改题授权时，指出这种结构问题，不擅自合并正文。标题已经完成导航时，正文直接进入内容。标题括号若承担另一项独立讨论，应调整章节归属。

无实质内容的栏目按授权删除。必须保留的栏目给出简短真实状态。巨大标题下面孤立的“无／暂无／没有”和为了凑目录补造内容，均损害阅读。标题确认内容对应、层级清楚、语言自然后结束，不追加文采加工。完整禁止项见[ORG-08](#org-08)。

<a id="org-05"></a>
## ORG-05 段落位置与层次

一个段落围绕主要任务安排材料，长度由内容决定。必要补充应围绕该任务展开。没有逻辑需要却在“背景—方法—评价—新背景”之间跳转，或在目标、实现、结果、价值、限制之间反复切换时，重新排列段落。

将同一理解步骤需要的定义、条件与说明放在便于连续阅读的位置。段落之间按问题、证据、比较或推导承接。句子组织与段内重复由[语言标准](prose.md)判定。

<a id="org-06"></a>
## ORG-06 列表与交叉引用

列表用于真正并列的事项、条件、步骤、选项、检查项和规则。实际两项就列两项；连续论证写成段落。为了凑三点、四点而制造分类或拆行，应恢复实际信息关系。

交叉引用为读者补充定位，当前句子仍交代其要表达的内容。“见第 X 章／详见附录／如图 X 所示／如下表所示”连续出现时，检查是否把主要信息交给了反复跳转。编号与回指用于实际检索和目标格式要求。

<a id="org-07"></a>
## ORG-07 版面安排

内容关系确定后，再安排分页、字号、表宽、间距、图幅和标题层级。保留事实、数字、判断含义和引用关系，优先保证实际可读性。

内容完整的短页可以保留留白；版面拥挤时重排合适的内容或调整版式。用空话填页、把不同逻辑挤成一段、把字号缩至难读，都会损害论文。

强调样式见[PROSE-09](prose.md#prose-09)，图表跨页与可读性见[VIS-05](visuals.md#vis-05)。

<a id="org-08"></a>
## ORG-08 论文题名与章节标题禁令

以下 14 项用于论文主标题及各级章节名称，覆盖研究论文、综述、理论文章、课程报告等学术任务。结合研究内容、目标格式和编辑授权确认，成立后必须纠正。标准判断标题表达了什么、遗漏或新增了什么；疑问词、冒号、字数和句法相似度只帮助定位。

1. **严禁机械疑问化。** 不得把方法、设置、结果等已有明确内容名称的章节批量写成“为什么采用……”“……怎样做”“从……继承什么”等授课问句。研究问题型标题须准确指向正文真正求解的问题。
2. **严禁冒号式包装。** 不得套用“主题概括：抽象关键词清单”“A 和 B：关键词一、关键词二与关键词三”“A：为什么采用……”等结构，重复概括、拼接讲解句或补齐关键词。换用破折号、顿号保留同一堆砌，仍须修复。正式副标题只有在补充必要研究对象、范围、文种或符合目标格式时保留其作用。
3. **严禁强行对立与递进。** 不得为了标题张力制造无研究依据的“从 A 到 B”“不是 A 而是 B”或“在 A 与 B 之间”，不得将章节顺序包装成认识、超越、变革等虚假进展。实际比较、推导和研究演变按真实关系命名。
4. **严禁文案化与标题钩子。** 不得在学术题名和章节标题中添加金句、俏皮比喻、营销口号、悬念、反问造势、强行升华或装饰性强调。删除此类加工后不另补一句宣传式结论。
5. **严禁写作过程播报。** 不得用“从燃料本身出发，再进入具体问题”“先了解……再看……”等讲述安排代替研究内容名称。实验流程、算法步骤属于真实对象，可以准确命名；作者准备如何介绍属于写作安排。
6. **严禁模糊日常表达。** 不得用“应用中要注意什么”“全链条里其实也有信息”“关于……的一些思考”等泛化表达掩盖对象或问题未确定。学术表达保持具体，不靠“其实、也有、里面”等词制造随意感。
7. **严禁关键词机械拼接。** 不得仅因关键词相关便用“与、和、中的、里的”等连接。标题中的对象、方法、变量必须有正文实际建立的关系；“五个环节里的计算机方法”等拼接应回到具体研究内容重新命名。
8. **严禁不自然的汉语结构。** 不得为压缩省掉必要关系，造成动作归属不明、修饰错位或技术词搭配别扭。“发动机参数在仿真中筛选”一类表达应确定研究操作后恢复自然名称，不能只调换介词或机械增加“的”。
9. **严禁抽象概念堆砌。** 不得以“价值、机制、路径、维度、能力、体系、挑战、启示”等替代实际研究对象和关系。领域中已定义的概念按准确含义保留；抽象术语有无作用由正文决定。
10. **严禁机械数字分类。** 不得为了目录工整凑出三重逻辑、四个维度、五条路径，或把段落数当成研究分类。实际分类、实验条件数量或模型阶数可以成为必要信息。
11. **严禁标题过度延长。** 不得将所有研究变量、实现模块、评价指标、结论和背景塞入主副标题。标题已能定位主要研究时停止补充；过长时重新选择研究重心，不能删掉关键范围却保留评价词。
12. **严禁全篇标题同质化。** 不得给不同章节统一添加问句、冒号、固定前后缀或等长修辞；不得把每节都写成“基于 X 的 Y”。真实并列的实验条件、标准章节和模板栏目保持协调，不为消除相似而强制改名。
13. **严禁无依据的判断与拔高。** 不得将未验证的设计目标、单次观察或局部结果写成题名中的“高效、稳定、普适”等已成立贡献，也不得隐去决定结论的范围。按[EVID-02](evidence.md#evid-02)和[EVID-08](evidence.md#evid-08)核对题名主张，保留有充分依据的明确发现。
14. **严禁标题与章节职责脱节。** 主标题必须对应全文研究，小标题必须对应本节真实内容与上级范围。不得只从摘要关键词、空提纲或相邻章节借词拟题；没有内容重心时先确认研究任务，不能靠题名包装掩盖缺口。

确认问题后按[ORG-04](#org-04)重新确定名称。仅改题时保护正文、数据、引文和已有研究判断；确需联动目录、正文中写明的章节名或元数据时，沿同一题名的实际引用处理。不得为了使新标题成立而新增结果或重写无关段落。

用户明确保留的题名、目标模板的固定栏目及引用文献的真实原题，按授权与来源身份处理。指出其适用问题时不静默改写来源元数据。不得仅因问号、冒号、合法术语或超出建议字数判错；也不得把已确认的内容失配降为可选文风。
