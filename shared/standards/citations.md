# 文献、归属与引证

文献存在、元数据正确和支持当前主张是三个分别判断的问题。排版工具不证明引证有效。

<a id="cite-01"></a>
## CITE-01 实际来源与访问状态【硬约束】
每条引用对应真实可定位来源；不得补造作者、标题、年份、DOI、页码或出版信息。检索摘要、全文已读、只读二手转述、无法访问等状态分开。

只取得摘要时，仅使用摘要实际支持的内容；不能声称核查过全文。网页搜索结果中的标题或 DOI 匹配不等于主张已核实。

<a id="cite-02"></a>
## CITE-02 主张与来源匹配【硬约束】
来源应直接支持对应句子的事实、范围、条件或方法。权威来源不能承担其中没有的细节；多个文献也不能合并成它们都未支持的结论。

重要转述保留定位线索，如页码、章节、图表或原文段落。自行综合产生的判断与来源报告的结果分开陈述，不通过一串引用掩盖推导缺口。

<a id="cite-03"></a>
## CITE-03 转述、引用与归属【条件要求】
保留他人的观点、方法、数据与图件归属；改写不免除引用。直接引文标识引号或规定格式，保留准确内容和位置；不得把翻译或拼接内容包装成逐字原文。

必要的作者式叙述、文献比较表可出现作者与年份，不因 SSOT 把它们从学术文本中删除。是否使用直接引语以及具体引证体例由文种决定。

<a id="cite-04"></a>
## CITE-04 版本与文献质量【条件要求】
按问题选择原始研究、综述、规范或其他适用来源，不把“新”当作唯一质量标准。对影响主要结论的来源，核对实际使用版本以及已知更正或撤回状态；预印本与正式版本不静默混用。

没有网络时如实记录无法更新验证，不虚构检索结果。参考数量来自论证需求，不以凑篇数替代覆盖相关证据。

<a id="cite-05"></a>
## CITE-05 元数据与引用系统【条件要求】
使用项目既有文献管理方式；LaTeX 中优先由唯一的 .bib 数据源生成参考文献。正文和表格的正常作者式引证允许存在，但不再手工维护一套完整且可独立修改的书目副本。

引用键与来源记录关联稳定。核对未引用条目、缺失键、重复条目及生成后的正文—书目对应；编译无报错不等于所有引文均有效。

<a id="cite-06"></a>
## CITE-06 投稿与研究声明【条件要求】
按目标要求处理作者信息、匿名稿、资助、利益冲突、数据/代码可用性、伦理与 AI 使用披露。需要何种声明取决于目标和研究内容，不在每篇论文中强制添加同一模板。

声明必须对应已知事实：数据未公开、代码不可访问或审批未取得时，不能写成已完成。涉及具体政策时读取用户提供的要求或当前官方文件；不把本标准当作某期刊的政策清单。
