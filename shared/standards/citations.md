# 文献与引证

<a id="cite-01"></a>
## CITE-01 来源身份与访问状态

每条引文对应真实可定位来源。作者、标题、年份、DOI、页码和出版信息据原文或出版记录填写。记录实际访问的是全文、摘要、元数据还是二手转述；已读范围决定可核查范围。

摘要支持的主张与已经核查全文是两种状态。只读到摘要就按摘要的实际内容引用，缺失信息保留待补位置。书目信息不得编造。

<a id="cite-02"></a>
## CITE-02 主张与来源匹配

引文靠近它支持的事实，使读者能辨认对象、条件和范围。保留页码、章节、图表或段落等定位。来源的权威性与引用数量，都不能让它们支持原文没有的细节。

综合判断说明多个来源之间的关系，区分来源报告的结果与本文推导。文献比较保留重要差异和异议；参考数量随论证需要确定。

<a id="cite-03"></a>
## CITE-03 转述、引用与归属

保留他人的观点、方法、数据和图件归属。转述保持原意并引用来源；直接引文使用引号或规定格式，保留准确内容及位置。翻译、拼接和概括按其实际性质标明。

作者式叙述、文献比较表中的作者与年份按目标体例使用。复用外部图件时核对原出处及所需许可或适用授权。

<a id="cite-04"></a>
## CITE-04 来源选择与版本

按问题选择原始研究、综述、规范或其他适用来源。质量依据与论证相关性决定选择，新旧程度是其中一个条件。

对影响主要结论的来源核对版本、更正及已知撤回信息，区分预印本和正式版本。外部核查受限时，记录具体来源和待核查内容。

<a id="cite-05"></a>
## CITE-05 文献维护与引用系统

使用项目既有文献库；LaTeX 由 `.bib` 维护元数据并生成书目。正常作者式引证是正文表达，完整书目数据由文献库集中维护。

引用键与来源记录稳定对应。检查重复条目、缺失键、未引用条目，以及生成后的正文—书目对应。语义匹配使用 CITE-02，构建检查按工具方法执行。

<a id="cite-06"></a>
## CITE-06 提交声明

根据目标要求和研究内容处理作者、匿名信息、资助、利益冲突、数据及代码可用性、伦理和 AI 使用披露。信息按实际状态填写，未知项列入待补材料。

涉及具体政策时读取用户提供的要求或当前官方文件。声明中的链接、审批和公开状态均需有对应依据。
