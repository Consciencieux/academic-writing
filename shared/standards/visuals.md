# 图表、公式与呈现

约束图表传递的信息及其忠实性，具体制作方法由 Guide 提供；LaTeX 与绘图软件的操作不属于本标准。

<a id="vis-01"></a>
## VIS-01 表达形式的任务【默认原则】
正文解释发现、关系和意义；表格适合精确查数或比较字段；图形适合展示关系、分布、趋势与结构。选择能回答当前问题的形式，不为“论文必须有图”制造装饰。

图、表、正文可引用相同数据，但每种形式有不同任务；不三处完整重复同一说明。示意图明确是概念表达，不能冒充实测结果。

<a id="vis-02"></a>
## VIS-02 数据与视觉诚实【硬约束】
图表数值对应可追溯数据及计算，保留单位、变量定义、转换和筛选依据。轴截断、对数坐标、归一化、平滑、聚合、剔除与不确定性表达不得造成未说明的误导。

坐标轴是否从零开始依图形编码和研究问题判断，不一律从零或一律截断。误差条要说明含义；缺少原始数据时不能生成貌似真实的点、误差条或显著性标记。

<a id="vis-03"></a>
## VIS-03 表格语义【条件要求】
同一列回答同类问题，同一行围绕同一对象。不要把来源、状态、用途、数值和判断硬塞在一个“说明”列；也不为形式整齐分裂本来一体的比较。

大段论证放正文，一两条信息可用句子。三线表、竖线、字号按投稿规范及可读性选择，不把某种 LaTeX 样式升格为普遍学术硬规则。

<a id="vis-04"></a>
## VIS-04 图注与自解释性【条件要求】
图注说明对象、分面、符号、单位及理解数据所需的条件；按适用要求解释样本量、重复测量、统计量和误差。正文承担更完整的解释与论证。

图注不应只剩“这是什么”而让图无法读懂；也不重复整段方法。期刊对图注具体长度和内容的规定优先；使用外部图件时给出实际来源并核实所需许可或适用授权。

<a id="vis-05"></a>
## VIS-05 可读性与实际渲染【条件要求】
检查缩放后的字号、对比度、图例、线型、分面一致性、可辨性与裁切；颜色不能是唯一的区分手段。调整尺寸不能删改数据含义。

实际查看生成图和最终文稿中的图；只检查绘图源码不等于看过图。未能渲染的范围单独记为未验证，不得捏造视觉检查结果。

<a id="vis-06"></a>
## VIS-06 公式、符号与交叉引用【条件要求】
符号在首次需要处定义，全文意义一致；公式中的单位、索引和假设可理解。公式可用于推导和精确定义，不能仅为显得专业而堆叠。

只给需要回指或模板要求的对象编号；正文、图表、公式的引用指向正确对象。证明细节按论证需要放正文或附录，不以“去重复”删除关键定义和推导。
