# 图表与公式

<a id="vis-01"></a>
## VIS-01 表达形式与任务

表格用于精确查数、比较和结构化字段；图呈现趋势、关系、比例、分布与结构；流程图呈现步骤顺序；架构图呈现组成关系；正文解释原因、意义与判断；来源用于回查。

同一数据可以支持多种形式，各自承担不同任务。“大表＋完整流程图＋大段解释”三次完整播报同一内容时，确定主要承载位置，其余形式改为补充理解。只提供装饰的图件删除。

<a id="vis-02"></a>
## VIS-02 数据与视觉编码

图表数值对应实际数据和处理方法，单位、筛选、聚合与统计量采用[EVID-07](evidence.md#evid-07)的口径。示意数据与实测数据保持可辨的身份。

坐标截断、对数轴、归一化、平滑和剔除都应有明确依据，并提供理解所需说明。轴起点依据视觉编码选择；错误的截断会夸大差异。误差条标明实际使用的统计量、样本数及计算方式。

手工改动几个点去对齐结论、补造实测点、误差条或显著性标记，属于数据表达错误。

<a id="vis-03"></a>
## VIS-03 表格语义与必要性

1. 表格服务于信息检索或比较，先明确它回答的问题。
2. 每列回答同一种问题，每行围绕同一个对象。
3. 填入数据后横向核对行对象，纵向核对列语义，逐项查看是否满足表头含义。
4. 来源、状态、金额、类别、用途、结论各自具有不同含义；需要同时呈现时，设置清楚的字段或必要注释。
5. “项目—说明”形式不能成为混放业务逻辑不同内容的理由。
6. 按实际比较关系决定表的数量和分组；既保持独立逻辑，也避免为正式感制造零碎小表。
7. 一两条信息优先比较正文与表格哪种更易理解。
8. 右侧单元格包含完整论证时，将解释移回正文，留下可比较字段。大量同类记录可分组、跨页、重复表头或放入明细附录；缩字和电报体不能修复语义混乱。
9. 完成后做必要性测试：删表或改成正文后，信息是否更难理解或检索？据此决定保留、拆分、重划字段或移出解释。

<a id="vis-04"></a>
## VIS-04 图注、表注与来源

图注交代对象、条件、单位、符号和分面，以及读图所需的样本量、重复次数和误差含义。表注交代单位、口径、来源和缺失状态。篇幅按读图需要及目标要求安排，完整结果论证留在正文。

复用图件依据[CITE-03](citations.md#cite-03)处理归属与许可。图表中文字采用[语言标准](prose.md)，特别核对短语关系、括号及强调。

<a id="vis-05"></a>
## VIS-05 可读性与版面

查看原图和嵌入论文后的效果，核对字号、裁切、换行、列宽、图例、线型、对比度及跨页表头。颜色配合线型、标记或文字区分对象。长单元格应仍能支持横向比较。

版式服从信息与目标模板。先处理语义，再调整图幅、表宽和排版；事实限定与字段含义保持完整。具体渲染操作见[文稿工具](../tooling/documents.md)。

<a id="vis-06"></a>
## VIS-06 公式、符号与回指

公式用于精确关系、定义与推导。首次需要时定义符号、索引、单位和假设，全文保持一致。推导、证明及附录的安排服从实际论证需要。

标签唯一，编号由文档工具生成，回指对应正确对象。修改或删除公式、图表后，核对符号重名、编号错位、悬空引用，以及正文仍在使用的旧字段。
