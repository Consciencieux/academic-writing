# 事实维护与完整删除

<a id="cons-01"></a>
## CONS-01 单一维护源

同一事实有一个权威维护位置，其他文件通过引用、解释、复用或自动生成使用它。可以重复表达，不应独立维护第二份副本。

重点包括参数、阈值、配置、日期、版本与状态；接口、字段与数据结构；规则和流程定义；实验结果、统计指标与表格中的可变数据。配置和数据文件维护数值，规范维护定义，代码提供实现行为，书目系统的维护见[CITE-05](citations.md#cite-05)。

LaTeX 可以通过宏、`\input` 或数据生成表复用同一事实。正文的独立解释保持与来源相同的口径。

示例：同一个阈值 `0.85` 在规范、方法章和 README 分别手填，修改时要记住三处。应选择一个维护位置，让其余位置引用或生成。两个偶然相等的指标仍是不同事实。

判断测试：这个事实明天变化，需要手动改几个地方？理想答案是一个。高频变化或高风险数据优先检查生成物是否过期。

<a id="cons-02"></a>
## CONS-02 研究快照

论文描述特定研究版本时，采用该版本的数据、代码、配置和定义。当前实现与历史实验分别保留身份，比较时交代各自条件。

版本冲突按[EVID-04](evidence.md#evid-04)处理。基线、消融、旧方案和历史资料是否保留，由当前研究问题与用户要求决定。

<a id="cons-03"></a>
## CONS-03 修改传播

新增事实前先找到已有来源，确定新增内容是引用、复用、生成还是独立事实。发现正文、表格和说明分别维护同一数据时，明确保留哪处、删除哪处、哪些改为引用或生成。

数值、定义、状态或术语变化后，按依赖关系处理正文、摘要、结论、图表、附录、书目、注释、模板和并行提交材料。优先更新来源并重生成，再核对手工表达。完成后搜索旧值、旧称和别名，消除同一事实的两种口径。

<a id="cons-04"></a>
## CONS-04 完整语义删除

用户要求删除概念、组件、接口、文件或方案时，清理授权范围内的直接引用、解释性引用和警告式引用。当前材料直接描述保留的方案。

**发现。** 确定对象及别名，检查文件名、源码、注释、文档、配置、测试、示例、提示词和生成物。论文还包括各章、摘要、图表及图注、脚注、附录、元数据和并行文本。搜索中文名、英文名、缩写、旧表头，并阅读“该模块／上述机制”等有关指代。

**清理。** 删除或重组有关内容，同步处理空栏目、悬空回指、失效测试、例子及生成数据。图件从来源重新生成。以下替代说明仍是残留：

> A 已移除；A 不再使用；A 已被 B 取代；此前使用 A；若出现 A 请删除；不要使用 A；旧的 A 方案；与 A 不同，当前使用 B。

**复查。** 在同一授权范围再次检索名称、别名及文件名，检查相关二进制或生成物，并回读受影响的句段、编号与链接。全部应清理引用消失、依赖关系恢复后完成。未读取文件或搜索失败的范围记为具体待办。

用户明确要求的历史记录、项目要求的变更记录和当前研究所需的基线、消融、相关工作，可在指定位置保留并说明用途。Agent 自行补写迁移说明来保存已要求删除的内容，不属于这种例外。

搜索命令、文件名核对及返回码处理见[搜索与复查](../tooling/documents.md#search)。
