# 中文学术表达

中文学术正文应准确、自然、具体、连贯。句子表达明确的对象、动作、事实和关系，段落围绕研究内容推进。语言形式服从实际论证，避免将论文写成工程说明、提示词、检查表或工作汇报。

<a id="prose-01"></a>
## PROSE-01 信息推进与语义重复

每个句段应承担实际的信息任务：提供事实、解释关系、呈现证据、作出比较、展开推导或建立必要承接。

禁止通过同义复述、重复解释和多层总结填充篇幅。

- 连续两句表达同一事实、原因或结论，即使更换措辞，也应合并或删除。
- 已经建立的因果、比较和判断关系，不得倒换说法后再次完整陈述。
- 禁止在完整结论后连续追加“换句话说”“进一步说明”“这意味着”“由此可见”等没有新增作用的解释。
- 禁止为了延长段落而补写空泛背景、价值、意义、过渡或总结。

**删除测试：** 去掉可疑句子，检查事实、推理、指代、必要解释和读者理解是否受到影响。没有实际损失的内容应删除。

必要的定义、解释和衔接应保留，即使它们没有引入新的外部事实。段落已经完成任务时直接结束。

跨章节的重复与主表达位置见 [ORG-02](organization.md#org-02)。

<a id="prose-02"></a>
## PROSE-02 自然陈述与模板腔

正文使用完整、符合中文习惯的陈述句。重要判断应体现当前对象的具体事实、条件和依据。

禁止以下机械表达：

- **字段腔：** 将连续正文写成“事实：……原因：……影响：……结论：……”等字段集合。
- **填空腔：** 只需替换名称、数字或时间，就能原样套用到其他对象的段落。
- **标签腔：** 用“影响有限”“较敏感”“风险较高”“优势明显”等孤立标签代替完整判断。
- **方面体：** 连续使用“在技术方面……在管理方面……在成本方面……”组织实际并不需要分类的内容。
- **固定开合：** 不同章节机械复用同一背景句、总结句、价值句或免责声明。

发现这些问题时，应回到当前材料，明确对象及其实际发生的变化、条件和结果，再组织成句。

表格字段、固定状态标签和确有分析意义的分类可使用相应形式；这些形式不得替代连续正文。

<a id="prose-03"></a>
## PROSE-03 句式、逻辑层次与机械对仗

正文直接陈述已经成立的事实和判断，句式由实际语义关系决定。

### 机械对仗与固定句式

**严格禁止为了制造对比、气势、层次或严谨感，主动套用对仗、排比和先否定后肯定的结构。**

重点识别：

> 不是……而是……  
> 是……不是……  
> 不在于……而在于……  
> 既……又……  
> 虽然……但是……  
> 不仅……还……  
> 首先……其次……最后……

尤其禁止先虚构一个正文并未提出的错误观点，再通过否定它强调真正的结论。

对于“不是 A，而是 B”式表达，首先检查 A 是否有独立论证作用。能够直接陈述 B 时，删除人为制造的对立部分。

对照、转折或顺序必须来自实际研究关系。只有确实需要纠正已有错误命题、比较相互冲突的判断或表达真实转折时，才保留相应结构。

禁止多个句子或段落连续使用相同骨架。实际并列内容允许不同长度、句式和重点，不强求对称。

### 长句与逻辑密度

- 禁止“一逗到底”，将多个条件、动作、原因、结果和例外塞进一个长句。
- 对象改变、条件切换或出现独立结论时，应按逻辑层次拆句。
- “因此、从而、同时、其中、由于、进而”等连接词必须对应真实关系，禁止用连接词掩盖推理缺口。
- 禁止为了所谓自然节奏而刻意交替长短句、加入不必要的口语或制造句法断裂。

长句本身没有问题，需要修正的是逻辑过载、关系混乱与指代不清。

连续机械重复“本文”“本研究”“本系统”“该方法”等主语时，可省略已知主体或直接进入动作与结果，同时保持指代准确。

<a id="prose-04"></a>
## PROSE-04 术语、抽象词与伪专业化

专业术语用于准确指称研究对象和概念。抽象词必须对应明确的事实、动作或关系。

重点警惕：

> 赋能、抓手、闭环、维度、范式、生态、路径、机制、体系、能力、价值、提升、保障、协同、智能化、优化、完善、增强

禁止将这些词连续堆叠，制造看似专业却缺乏具体内容的句子。

**判断测试：**

1. 这个词具体指向什么对象、动作或关系？
2. 当前材料是否提供了相应内容？
3. 删除它后，事实、动作和结果是否发生变化？

无法回答前两项，或删除后没有实质信息损失时，应删除抽象词，改为具体陈述。

尤其要清理“能力建设、体系完善、机制优化、价值提升、协同增强”等只有抽象动作、没有实际对象与结果的表达。

学科必要术语按其准确含义保留，并在首次需要时定义。同一概念保持主称谓一致，不得为了避免词语重复而随意切换“抽取、提取、读取、抓取”等可能存在差别的术语。

<a id="prose-05"></a>
## PROSE-05 电报体与过度名词化

**禁止在连续正文中使用关键词、名词短语或动词短语堆叠代替完整句子。**

典型错误：

> 实现 A、B、C；完成 D、E、F；具备 G、H、I。

同样需要清理连续使用“XX 化、XX 性、XX 能力、XX 体系、XX 机制、XX 建设”等结构制造的伪专业化表达。

不得将一组动作压缩成斜杠、箭头、分号或并列名词，让读者自行推断其对象、条件与因果关系。

**修正方法：** 将实际动作恢复为谓语，说明动作由谁执行、作用于什么对象、在什么条件下发生，以及材料支持什么结果。多个独立判断分别成句，按真实逻辑连接。

例如材料涉及请求入队、线程取出请求和执行上限时，正文应直接说明这些行为及其关系，而非概括为“队列化承载、并发化调度、全链路闭环”。

标题、表头、流程节点和提纲可以采用短语；论文中的连续论证必须形成完整、可理解的陈述。

<a id="prose-06"></a>
## PROSE-06 防御性否定、免责声明与限制

证据支持的结论应直接陈述，并将实际适用范围放在对应主张中。

**严格禁止在完整判断之后追加没有独立信息作用的否定、免责声明或自我辩护。**

典型错误包括：

> 这并不意味着……  
> 这不代表……  
> 也不能据此认为……  
> 本工作不宣称……  
> 需要特别指出的是……

重点清理以下行为：

- 先提出正文原本没有涉及的误解，再将其否定。
- 在明确结论后连续追加否定、再否定和进一步限定。
- 为显得谨慎或严谨，反复声明研究没有证明其他无关命题。
- 把内部的证据检查、工具访问限制或执行状态写成论文免责声明。
- 在结果、讨论和结论中反复说明同一个已明确的限制。

**限制必须有真实触发条件。** 例如实验条件直接影响结果解释、指标确实排除了某项测量、材料缺失改变结论范围，相关信息就应进入对应论证。

**删除测试：** 删除否定或限制后，如果事实、适用范围、推理关系与读者理解没有实质变化，该内容必须删除。

真实负结果、失败事实、排除条件、证据缺口和必须纠正的错误命题应准确陈述。保留的是它们提供的信息，无须附加进一步的防御性解释。

<a id="prose-07"></a>
## PROSE-07 数字叙述与案例

数字用于支持判断，正文负责解释其关系和意义。

禁止将表格数值依次搬入正文，形成长串数字后再附加一句空泛结论。

正文应选择与当前判断直接相关的数据，说明比较对象、重要变化及必要条件。数字、公式、变量与限定过多时，按实际逻辑拆分成句。

已有表格承载完整数据时，正文重点解释关键发现，不逐项朗读表格。

案例应说明当前对象发生了什么、有什么证据、哪些条件影响理解，以及它怎样支持本段论点。禁止将案例写成字段转录，也不得让不同案例机械套用同样的句式和篇幅。

## PROSE-08 括号、破折号与尾部挂载

**禁止把关键事实、主要条件、因果关系、完整解释、核心定义或重要结论塞进括号。**

重点禁止：

- 连续使用多个括号说明正文信息。
- 括号嵌套、长括号及“主句＋长括号＋继续补充”的结构。
- 在普通名词、短语或完整句子后机械附加解释性括号。
- 用小标题中的括号承担第二层标题。
- 把一个完整判断写在括号内，让读者必须阅读括号才能理解主句。

重要信息应进入主句或独立分句。括号仅保留简称、别名、单位、引用及其他简短的次要信息。

**判断测试：** 括号里的内容是否是正文真正要告诉读者的事实或判断？如果是，就把它移入句子结构。

同样严格限制尾部挂载：

- 连续使用破折号补充条件或解释。
- 用分号串联本应独立的判断。
- 在主句结束后反复追加“此外、同时、其中、即、也就是说”等补充。
- 用否定尾句或多重限定反复延长已经完整的陈述。

出现这些问题时，应重新组织整个句子。禁止只把括号换成破折号、把破折号换成分号，保留原来的信息堆叠。

标题层级问题由 [ORG-04](organization.md#org-04) 处理。

<a id="prose-09"></a>
## PROSE-09 引号、加粗与装饰性强调

**普通正文默认使用常规字重。禁止给普通词语、动词、评价词和完整结论随意加粗。**

重点禁止：

- 为突出“重要”“关键”“核心”“优势”“机制”等普通词语而临时加粗。
- 在同一段中反复加粗多个词语或短句，制造虚假的视觉层级。
- 给普通名词或判断添加装饰性引号，使其看起来像特殊术语。
- 同时叠加黑体、引号、斜体、下划线、色块、大字号等多种强调。
- 用字体变化代替实际的论证重点或内容层次。

**正文中的 Markdown `**…**`、LaTeX `\textbf{…}` 等显式强调，应逐处核对用途。缺少明确依据的装饰性强调必须删除。**

标题、表头、正式定义、直接引语和目标格式明确规定的字形按其实际要求处理。数学符号的规范字形也应保留。

引号用于名称、真实引用或明确讨论某个词语本身。不得通过随意加引号制造“专业概念”。

真正重要的结论应通过内容、证据和合理位置突出，而非通过装饰突出。

<a id="prose-10"></a>
## PROSE-10 工程材料、元话语与过程播报

论文正文面向读者陈述研究内容。

从代码、设计说明、接口文档、提交记录、实验日志和聊天材料中提取有依据的事实、方法与结果，按学术论证重新组织。

**禁止直接将以下工作交流内容写进论文：**

- “按要求修改”“上次讨论”“已完成检查”等执行汇报。
- Agent 的任务安排、进度承诺、内部判断记录与工具调用过程。
- 与研究内容无关的 prompt、payload、fallback、JSON 字段、函数名或内部状态名称。
- 将工程文档的字段顺序直接复制为论文段落结构。

工程实现确实是研究对象时，应使用准确术语说明实现方法；对话与日志本身属于研究数据时，保留其必要内容及出处。

### 元话语与过程播报

严格限制以下表达的机械使用：

> 本节将……  
> 本部分主要介绍……  
> 下面介绍……  
> 接下来讨论……  
> 下表汇总……  
> 首先……然后……接着……最后……

禁止用这些句子复述标题、宣布写作计划、重复已经呈现的流程，或代替实际研究内容。

正文应直接进入需要交代的事实、方法、证据与判断。交叉引用用于必要定位，流程叙述用于交代确有阅读价值的步骤及其关系。

章节标题与交叉引用的安排见 [ORG-04](organization.md#org-04)、[ORG-06](organization.md#org-06)；图表与正文的分工见 [VIS-01](visuals.md#vis-01)。
