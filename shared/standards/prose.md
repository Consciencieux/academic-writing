# 学术语言与信息表达

以下多为写作默认值，需要结合文种和语境判断。它们不是词语黑名单，也不用于机械降低所谓“AI 检测率”。

<a id="prose-01"></a>
## PROSE-01 自然陈述与对象特异性【默认原则】
以完整、自然的陈述表达对象、动作和关系。句式由当前研究内容决定，不强迫每段都用“事实—原因—影响—结论”或固定三点。填空式同构、孤立评价标签和无对象的套话需要具体化。

字段、图节点、表头、提纲可以使用短语。领域标准句式和规范用语可复用，不能只因“换个对象也能用”就全部重写。

<a id="prose-02"></a>
## PROSE-02 语义推进与重复【条件要求】
句内及段内避免同一事实、关系或结论的无功能反复。后文可解释、提供依据、限定、对照、建立指代或衔接；是否保留取决于读者需要，而非每句必须有新事实。

同一结论连续换成“换言之—这意味着—由此可见”而没有作用时合并。跨章主表达位置由 ORG-02 判断，不在此另建一套规则。

<a id="prose-03"></a>
## PROSE-03 句式与逻辑密度【默认原则】
长句可以承载紧密关系；对象频繁切换、条件和例外堆叠、多个结论一逗到底时拆句。并列、对比、排比、首先其次都可以表达真实关系，不作为默认装饰。

保持必要的主语与指代。连续同主语未必有错，改变它不能造成歧义；不为了“自然”刻意添口语、断裂、语病或随机长短句。

<a id="prose-04"></a>
## PROSE-04 术语、抽象词与语言版本【条件要求】
同一概念的主称谓一致，首次出现按读者需要定义。抽象术语、名词化和常用学术表达在承载明确含义时保留；空泛的能力、价值、机制叠加应改成实际动作或关系。

中文与英文遵守各自惯用表达，不逐词翻译中文禁令。保留学科必要术语及正常作者式引文；普通读者不需要的内部字段、任务名和实现黑话应解释或改写。lint 词命中只是复核线索。

<a id="prose-05"></a>
## PROSE-05 边界、否定与解释【条件要求】
限制、否定与例外应改变事实解释或适用范围。证据充分的结论直接写；不要先虚构一个读者误解，再连续否定。删除不影响含义与阅读的防御尾句，保留会影响理解的限制。

段落开头可以交代研究背景、知识缺口、定义或目标，前提是为当前读者建立必要理解。禁止的是无关宏观背景和模板铺垫，不是背景本身。

<a id="prose-06"></a>
## PROSE-06 数字、括号与强调【默认原则】
正文选取论证所需数字，不朗读全部表格。判断与数据的先后由读者理解决定，不统一强制“结论先行”。关键条件和结论进入主要句子结构，简称、单位、引用等次要信息可放括号。

引号用于引用、名称或讨论词语本身；加粗、斜体、字号依目标格式与层级使用。避免同时叠加装饰、不断尾挂括号或破折号。合法强调与学科书写习惯不构成错误。

<a id="prose-07"></a>
## PROSE-07 材料体裁与正文【条件要求】
从代码、工程说明、聊天、日志中提取有证据的研究内容，按读者问题组织；不要直接搬入工作指令、修改播报、进度承诺和 Agent 自证。

若对话、日志、软件流程本身是研究对象、方法证据或合规复现材料，可以按研究需要引用，保留必要上下文与隐私处理。先判断其学术功能，不能仅凭“Agent”“日志”或内部名称删除。

<a id="prose-08"></a>
## PROSE-08 案例与开合【默认原则】
案例体现当前对象如何支持论点，选取改变理解的事实、条件与结果；不逐项转录字段。不同案例的证据不同，结构和长短应允许不同。

章节开合与元话语服务导航或论证。标题已足够定位时无需复述标题；长篇中确有必要的承接和总结可以保留，不要求所有章节都有或都没有小结。
