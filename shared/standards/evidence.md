# 事实、证据与推导

约束主张为何成立，不规定段落句式。CORE-02、CORE-03 是共同底线；以下标准用于具体判断。标为“硬约束”的事项不因文体偏好改变。

<a id="evid-01"></a>
## EVID-01 事实与新推导【硬约束】
事实来自可定位材料、已验证知识或明确计算。推断应有可复述的依据与推导关系；评价要有比较标准。可以提出假设、理论证明、解释与设计方案，按其性质陈述。不能为文本完整虚构实验、经历、日期、数字或文献。

检查：主张被表述为“发生过的观察”，还是“根据材料得到的推导”？新推导不是新增原始事实。无依据的完美结论不能通过补一个引用变为有效。

<a id="evid-02"></a>
## EVID-02 强度、范围与比较【硬约束】
判断匹配对象、时期、样本和指标口径。比较交代基准与条件；“差异”本身不等于“优劣”。一次出现不等于长期，比例高不等于影响严重，设计目标不等于已实现能力。

“显著、完全、关键、证明、导致”等词需要对应证据，但词本身不构成违规。证据足以支持明确判断时应直接作出判断，不自动弱化成可能性。

<a id="evid-03"></a>
## EVID-03 未知与异常【硬约束】
零值、缺失、未披露、提取失败、尚未核验、未发现分开记录。无法取得的数值不能填成零。关键冲突、无法闭合的计算与范围不符应影响结论，不为完成段落而隐藏。

异常只阻止依赖该异常的主张；其余证据充分的部分继续完成。工作缺口放在批注或工作记录；论文中的限制只保留影响读者理解的内容。

<a id="evid-04"></a>
## EVID-04 冲突来源【硬约束】
先比较来源版本、对象、定义、统计分母与时间，而非按“看起来权威”静默选一个。能够解释的差异明确归因；不能解决的冲突保留，并限制受影响的判断。不得改写原始材料使其看起来一致。

<a id="evid-05"></a>
## EVID-05 因果、机制与证明【硬约束】
时间先后、相关、机制猜想不能直接当作已识别的因果效应。因果表述说明支持它的设计、假设、识别条件或直接证据；机制解释可以作为解释性假设，不能借“可能”暗中传递已证实结论。

理论工作允许由定义、假设与有效推导得到新结论；区分证明、数值例证和实验支持。常规形式推导无需被误判成“材料里没有的新事实”。

<a id="evid-06"></a>
## EVID-06 数字与复算【硬约束】
保留原始值、计算值、展示值的区别，给出单位、分母和必要公式。检查零分母、近零分母、缺失值及异常输入。计算使用未舍入数据；展示精度与测量依据匹配。

实验汇总明确重复次数、独立样本或重复测量、统计量和不确定性含义。标准差、标准误、置信区间不可互换；统计检验、效果量和统计显著性按实际分析报告，不凭词语推测结果。

<a id="evid-07"></a>
## EVID-07 主张覆盖与研究报告【条件要求】
关键主张要有对应证据位置或明确推导；重要负结果、与预期不符的观察不能因不利于叙事被省略。经验研究交代足以解释结果的设计、对照、样本、指标、处理与复现条件；理论工作交代假设与推导。

不强迫所有论文报告同一套实验字段。研究类型触发其适用要求；没有开展的实验、统计检验或伦理审批不能补写为已完成。

<a id="evid-08"></a>
## EVID-08 分类、能力和意义【条件要求】
分类应服务实际差异与研究问题，不为凑三类四类造框架。评价指标到质量、风险或价值之间需要比较标准或解释。能力宣称要区分已实现、已测试、设计目标和拟开展工作；用观察与论证呈现贡献，而不是不断自评“先进、可靠、有效”。
