# 证据与判断

<a id="evid-01"></a>
## EVID-01 事实、推导与评价

事实对应用户材料、可靠来源、明确上下文或可复算的数据。推导说明所用事实、假设和推理关系，评价说明采用的标准。写作时根据这三种性质选择表述，让读者能辨认观察结果与作者的判断。

材料支持到哪里，就据此形成主张。需要新增研究信息时，先取得来源或实际计算结果。编造数字、经历、时间、来源、观点或实验细节，以及为使来源一致而改写原始记录，均属于事实错误。

理论推导、证明、解释和研究设计可以形成新结论，其依据是定义、假设和有效推理。表达性修改沿用原有事实与结论；实质研究修改交代新增依据、定义或计算口径。

<a id="evid-02"></a>
## EVID-02 强度与适用范围

重要判断说明依据，并匹配研究对象、时期、样本和统计口径。证据充分的结论直接陈述；范围有限的发现，在对应主张中写明实际条件。

一次观察支持该次事件，一个案例支持该案例的发现，一个时期的数据支持该时期的判断。长期趋势、跨样本规律和总体结论需要相应的时间跨度、样本或适用的推导依据。局部材料的覆盖范围也是结论范围的一部分。

“必然、完全、严重、显著、普遍、长期、决定性、核心原因、证明、依赖、导致”等词，以及“更好、更差、明显、较高、较低、重要、关键”等程度词，各有相应的证据负担。按实际支持强度使用，保留已经成立的明确判断。

示例：给定同一负载下平均耗时由 100 ms 降至 88 ms，可写“在该测试负载下，平均耗时降低了 12%”。

<a id="evid-03"></a>
## EVID-03 未知、缺失与零值

按实际证据状态记录信息：

- **没有／零值**：有依据确认对象不存在或数值为零。
- **未发现**：在已执行的检索或观察范围内没有发现。
- **未提供／未披露**：所读材料未给出这项信息。
- **未知／无法判断**：现有材料不足以确定状态或形成判断。
- **无法核实／尚未核验**：候选信息的真实性尚待核对。
- **提取失败**：获取过程没有成功取得材料中的信息。

缺失保留为空值及其状态；统计时依据处理方法决定剔除、插补或单独报告。0 表示经过确认的零值。没有找到证据不等于证明不存在，提取失败不等于数值为零，尚未核实不等于已经确认。

<a id="evid-04"></a>
## EVID-04 冲突来源与异常

不同数字、定义或结论出现冲突时，先比较来源版本、研究对象、时间、分母、单位与统计口径。能够解释的差异按其原因分别使用；仍影响判断的冲突保留具体位置和待解决事项，调整相应主张。

原始资料保留其来源内容，纠错或重算形成有依据的派生结果。来源冲突、关键数据缺失、时间不匹配、计算不闭合及输入矛盾，都应在形成结论时处理。影响论文解释的异常进入相关论证，材料获取的待办留在工作记录。

<a id="evid-05"></a>
## EVID-05 比较、指标与评价

比较交代对象、指标、计算口径、条件和时间范围。指标首先反映其定义的维度；从数值到质量、风险或效果的评价，还需要比较基准、评价规则或相关事实。

“比例较高”与“风险较高”之间需要说明判断依据；“存在差异”与“其中一方更优”也有不同的证据要求。判断依赖多个条件时，把决定结论的条件纳入比较。

“高比例、高敏感、高风险、高质量”作为字段或标签时使用已定义的分类标准，正文评价则给出对象及依据。

<a id="evid-06"></a>
## EVID-06 因果、机制与证明

因果判断依据适合当前问题的实验设计、识别条件、直接证据或已经建立的机制，并说明其适用假设。时间先后、共同变化和统计相关本身不足以证明因果。

观察只支持共同变化时，就陈述共同变化；机制属于解释性假设时，交代该解释所依据的观察和待验证关系。“可能相关”“与……一致”“可能受到……影响”等表达应保持相应强度。

“因此导致……”“由此造成……”“说明……是主要原因……”需要因果依据。理论结论由定义、假设和推导建立，数值实例与实验分别提供实例核对和经验支持。

<a id="evid-07"></a>
## EVID-07 计算、精度与统计

保留原始值、计算值和展示值。重要数字可以由来源数据、公式、单位及分母重新得到；计算使用原始精度，展示采用与测量依据相称的小数位。

分母为零、接近零、缺失或异常时，先确定该指标是否有定义及怎样解释，再计算。四舍五入的展示值用于阅读，复算使用未舍入数据。尾差按统一口径说明。

统计汇总交代样本数、独立样本或重复测量、统计量与所用方法。标准差、标准误、置信区间分别有明确含义；统计显著性、效果量和不确定性依据实际分析报告。重要计算尚未复核时，相应结果保留待核实状态。

<a id="evid-08"></a>
## EVID-08 能力、贡献与分类

功能和效果按实际状态表述：设计目标说明拟达到的行为，实现说明已有功能，测试说明已观察到的结果。可靠性、稳定性、效率及优势等主张，分别以对应实验、数据或明确依据支撑。

贡献通过事实、比较和推导呈现。“有效、可靠、先进、合理”等自我评价，以及连续使用“验证了、说明了、体现了、证明了”，只有在准确表达具体证据关系时才承担信息。

分类依据材料中的稳定差异，并服务研究问题。实际关系需要几类就分几类；类别应有区分依据，对象间的交叠也按实际情况表达。单个指标名称或整齐的分类框架不单独构成评价证据。
