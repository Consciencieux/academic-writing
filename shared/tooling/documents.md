# 文稿工具

## 读取和编辑

使用宿主提供的文档、PDF、检索和图表工具，按其要求加载操作技能。Markdown 读取正文及必要素材，Word 读取正文、表格和有关脚注批注，PDF 结合文本抽取与页面查看。原始文本优先，图表与抽取不完整处查看实际页面。

读取结果遇到分页或截断时接续。编辑优先使用文稿源文件；仅有 PDF 时可以交付页码定位的修改稿。需要原格式成品时，用相应工具保存并预览。

## 候选检查

```bash
python /path/to/skill/scripts/lint_text.py /path/to/paper.md --json
python /path/to/skill/scripts/lint_tex.py /path/to/paper --json
```

[文本检查器](../../scripts/lint_text.py)扫描 Markdown 和纯文本，[TeX 检查器](../../scripts/lint_tex.py)扫描静态包含文件。两者使用[共同语言模式](../../scripts/language_checks.py)，返回位置、规则 ID 和待核对内容。

Markdown 扫描正文和表体，屏蔽代码、引用块、标题与表头。TeX 扫描已识别段落和表格行，屏蔽代码环境。语言覆盖黑话密集、短语堆叠、强调、括号、重复和长单元格；语义审查同时阅读被屏蔽的有关内容。

`--max-comma` 设置单句逗号提示阈值。文本检查器的 `--max-cell` 设置单元格长度提示阈值。`--severity` 筛选显示级别，`--fail-on` 设置全部扫描结果的失败门槛。退出码：0 为低于门槛，1 为达到门槛，2 为输入或资源读取失败。

## 结果处理

静态工具提供候选位置，编译器生成文稿，Agent 根据标准判断语义并查看成品。依次完成适用的工作，记录各自产物和实际覆盖范围。

工具失败时，依据错误消息修正路径、编码或构建配置后重试。尚缺工具或材料的事项写成具体待办。对论文解释有影响的信息进入相应章节，操作记录留在工作反馈。

## 搜索与复查

在授权根目录使用现有搜索工具查名称和别名，另取得文件名检查。示例命令：

```bash
rg --hidden --glob '!.git/**' -n -F -- '目标名称' .
rg --files --hidden --glob '!.git/**'
```

按任务范围选择路径与忽略规则。完整删除时同时检查被默认忽略、但属于本次目标的生成目录，可对这些目录追加 `--no-ignore` 搜索。文本、图件及其他二进制文件分别用适合的读取工具检查。

`rg` 返回 0 表示有命中，1 表示本次搜索无命中，2 表示出错。文件名清单用于核对名称；文本和文件名完成检查后，再复查图件、生成物与相关指代。

## 成品

预览关键页面、图表、图注、公式、分页及元数据。检查裁切、换行、字号和回指；格式改动保持事实、口径与引文关系。TeX 构建方法见[LaTeX 操作](latex.md)。
