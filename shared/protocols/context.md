# 上下文、完整读取与任务交接

## 读取当前需要的完整资料

执行入口负责按当前操作选择参考文件。开始对应操作前，从第一行读到文件末尾，覆盖其中的规则、具体判定、例外和示范。分块读取时连续接续；工具显示分页、截断或未返回的剩余范围时，继续读取未读部分直到末尾。

搜索结果、目录、锚点和摘要用于定位。首次调用一份参考文档时完整读取该文件；已完成全文加载后的针对性回查，可以读取相关完整章节，连同其判定、例外和示范一起使用。

按入口匹配到的文件，以及当前方法明确要求读取的文件，组成当前资料范围。参考文档中的其他链接用于关联与定位；进入相应操作或判断确实需要其内容时，再完整加载所指文件。

资源复用要求同时满足：本轮有效上下文已完整包含原文、文件内容未变、当前任务与适用条件仍一致。当前上下文只剩摘要、文件路径或“已读”记录时，重新读取所需文件全文。读取失败时先处理路径或访问问题，依赖该资料的操作在取得原文后继续。

## 任务材料

一句或一段的任务使用原文、附近段落、目标及相关来源。多章或跨会话任务沿用项目工作记录；需要建立记录时使用[工作状态片段](../../assets/writing-state.md)。

记录文章目标、已作决定、当前位置和下一步，再附正文、数据与文献的位置。数据和书目分别由原文件维护，状态记录保存定位信息。交接时保留当前操作和恢复所需的资料路径，恢复后据此读取原文。

## 刷新事件

| 事件 | 继续工作前的读取动作 |
| --- | --- |
| 进入新任务或切换 Guide / Audit | 读取当前执行入口、成文核心与本协议，再按当前操作完整加载适用资料；符合上述复用条件的资源可直接使用。 |
| 同一写作单元内连续修改 | 沿用仍可直接使用的完整资料，回读实际修改的句段及其上下文；新增操作按入口补读相应文件。 |
| 切换章节或进入新的实质写作单元 | 回读当前入口的重点要求和成文核心，读取本章目标、前后承接位置及本章证据；补读新增任务资料。已加载规则按当前问题定向回查。 |
| 结束多轮资料讨论、长篇检索或工具排错，返回中文成文 | 回读成文核心，重新完整读取语言标准与成文方法，再回到待写位置、相关材料和已定主张。 |
| 发现机械对仗、空泛术语、电报体、防御性尾句等表达回退 | 定向回读对应标准的完整章节和相关成文方法，按原材料重写受影响的完整句段，再继续写作；原文已退出有效上下文时重新完整加载所在文件。 |
| 新会话、上下文压缩或只能取得此前的摘要 | 重新完整读取当前执行入口、成文核心、本协议及当前操作所需参考文件，再读工作状态和待处理正文。中文成文重新完整读取语言标准与成文方法；审查重新完整读取当前范围适用的标准与方法。 |
| 规则文件、来源或正文发生修改 | 完整重读改变的参考文件，读取改变的材料与正文，并更新依赖它们的判断和位置记录。 |

按一组完整段落、一节或一章持续工作。刷新在上述任务事件发生时执行，完成后立即返回当前写作或审查。发现具体语言或事实问题时回查其标准和原文，重组受影响部分。

## 交接

交接携带任务、授权范围、文稿版本、正文与证据位置、已定判断和待处理事项。全文审查的分批记录包括已读章页和主要职责，批次完成后汇总比较。

工作完成后交付本次产物；尚缺材料的事项说明所需输入和影响位置。读取与恢复过程留在执行上下文，正文继续承载研究内容。
