# 论文项目指令片段

将下列段落合并进论文项目的 AGENTS.md。

```markdown
## 学术论文

写作、续写和修订使用 academic-writing-guide；只读审查使用 academic-writing-audit；多步骤任务使用 academic-writing。读取相应执行入口并按其加载和工作流程继续。

生成或改写中文学术正文前，按 Guide 完整读取语言标准与成文方法，使用具体的对象、动作和论证关系写作。保持明确判断，保留必要条件；清除空泛术语、电报体、无功能的防御性尾句、装饰性强调和工作过程播报。

切换章节时恢复核心要求与本章任务；从多轮资料讨论或工具排错返回成文时重读语言标准与成文方法。新会话或上下文压缩后，重新读取当前角色入口及其指定资料，按上下文协议恢复工作。

以本项目正文、研究数据、文献和目标格式为材料。长任务沿用现有工作记录，保存目标、决定、当前位置和证据位置。LaTeX 中间文件与构建目录不提交。
```
