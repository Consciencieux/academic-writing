# 虚构表格草稿

材料只有三项：记录来源为测试日志；方案状态为未完成测试；三次测量中位耗时为100毫秒。这三项并不是三个相同类型的方案。

| 项目 | 指标 |
| --- | --- |
| 日志 | 原始测试记录 |
| 测试状态 | 未完成 |
| 方法A | 100毫秒 |

下面表中的右列用连续论述替代了比较字段：

| 对象 | 说明 |
| --- | --- |
| 请求队列 | 请求队列保存待执行的请求，线程空闲时取出队首请求。同一时刻最多执行四个请求，这一限制是当前调度设置的一部分。输入记录包含进入队列与结束执行的时刻，但尚没有证据支持吞吐量提升或稳定性结论。这里把方法步骤、配置限制、数据字段以及结果边界一起放在一个单元格中，读者不能根据这一列迅速比较两个对象，而必须逐字读完各段。 |

不得添加材料没有的实验数据。先判断这些信息应该如何表达，再修改形式。
