# 固定行为评估

`cases.json` 给出任务、材料、适用标准、期望与应避免结果。fixtures 均为虚构评估材料，不能移入真实论文。自动测试只核对资源和脚本；模型行为须在实际客户端运行。

## 执行

把任务和对应材料交给被测 Agent，不把 expected/avoid 作为提示泄露。对多轮用例按 turns 顺序执行；新会话步骤只转交实际保存的正文和工作状态，不复制先前的规则上下文。目录删除用例先复制 fixture 工作区，授权修改这个副本。

记录模型、客户端、实际读取文件及完整范围、输出、工具调用、运行条件和修改次数。目标对照由实验选择，不能假定新实现更好。每种任务重复运行，尤其观察后续章节和恢复后的退化。

## 区分三类失败

1. 没加载：相关工作、摘要或图注跳过共同语言规范，或只读目录/前几行。
2. 已加载但未执行：仍写黑话、电报体、无理由加粗、混乱长表格，或删除后留下活动及否定式引用。
3. 误用：机械删除术语、表头、必要限定、引用或正常研究内容。

写作评价看事实不变、中文自然度、信息推进与人工修订量；审查看真实问题召回、误报、定位和改法。删除用例检查实际文件与搜索结果；表格用例检查行列语义与必要性，不只看行数。明确记录工具不可用、未渲染和未核实范围。

读取成本按实际读取字节或宿主可用 Token 计数，单独记录目录往返与重复加载。不能把文件数量、禁词命中数或一句“已遵守”当遵循率。运行结果可保存到 `evals/runs/`；该目录不自动入库。
