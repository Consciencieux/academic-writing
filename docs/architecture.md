# 架构

## 目标

减少重复式“写—审—补丁”，让 Agent 用恰当的材料、论证安排和表达方法产生更好的初稿。完整可用同时需要可执行方法、准确判定、可访问资源和真实行为评估，不能用规则条数或 CI 绿色替代。

## 两个拆分轴

**执行轴按用户动作拆。** 协调入口分派任务；Guide 规划、生成和修订；Audit 只读诊断。篇幅、图表、参考文献与文章章节都不是新的角色。检查并修改是一个可直接完成的联合任务。

**知识轴按判断对象拆。** 证据是否成立、内容放在哪里、语言如何表达、图表是否忠实、引用是否支持主张、事实怎样保持一致分别有标准。章节写法作为方法导航，不能切断横跨章节的证据与引证规则。

正面/负面是表述方式，不是职责边界。一个“不要因去重复删掉定义”仍是写作默认值；“准确交代数据来源”仍是硬要求。标准保存判定和适用条件，方法保存输入到成品的决策过程，审查方法保存如何获得足够证据并定位问题。

## 规则的性质

共同核心在两个执行入口中以生成块存在，只有一个编辑源。它足够短，覆盖任务、证据、原始材料、角色、上下文与完成边界；专门规范不全部常驻。

标准区分硬约束、条件要求和默认值。硬约束主要维护事实诚信、证据与真实工具状态；默认值服从文种、学科、目标格式与可读性。正常背景、衔接、术语、作者式引用、必要概括和有效新推导不被一概禁止。理论证明、消融、研究历史及目标模板按实际学术功能保留。概念清理只针对当前不应继续存在的活动引用。

## 加载与上下文

Skill 入口含最小核心和确定的任务加载表。短润色不加载全部图表/投稿材料；多章任务加载章节分工与上下文协议。概念或数据变化按依赖传播，状态摘要不充当证据。

长任务恢复时读取当前入口、方法、正文位置与相关来源。入口不是每段必须背诵的文档；没有客户端支持也不宣称发生了自动注入。项目 AGENTS 片段帮助激活，而不是把全部文稿规范塞进永久提示词。

只有核心是生成式投影。源代码与发布包的路径转换在构建时完成，执行时只读真实相对链接。根 `SKILL.md` 是协调入口的唯一源码。

## 可靠性的来源

生成前确定当前论证任务与可用证据；生成时采用正向成文方法；生成后核对本次变化。独立 Audit 留给明确审查需求、重要结构变化和最终交付。已经解决的问题不因风格偏好反复打开。

Audit 把全文读取、引文核实、数据复算和成品查看分开；未知不是错误，关键词命中不是判决。判断输出有定位、证据与明确推荐，而不是只给候选清单或免责说明。

静态 lint 负责发现有限候选，编译器负责真实构建，视觉工具负责实际呈现，模型负责语义关系。各自只报告做过的验证。评估用正常表达的反例约束误报，避免把谨慎和删短当作写作质量。

## 范围

本包提供通用执行方法、六领域标准、可安装包与固定测试材料。它不把所有领域写成同一种论文，也不内置会过期的每家期刊细则。目标要求由用户材料或实际官方文件提供。

在真实模型与客户端上运行固定用例后，再决定是否需要更多示例、细分方法或专门工具；优先修会影响初稿与判断的缺口，不先扩大 Skill 数量。

## 外部依据

Agent Skills 的渐进加载、相对资源和入口格式见 [官方规范](https://agentskills.io/specification)。短入口、明确方法、真实测试的设计依据见 [Anthropic 的 Skill 编写指南](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices)。这些文档支持加载与测试设计，不证明本包已经改善模型质量。

[OpenAI 技能文档](https://developers.openai.com/codex/skills)及 [AGENTS.md 文档](https://developers.openai.com/codex/guides/agents-md)用于核对客户端接入方式，实际安装以客户端当前支持为准。

[Nature 格式指南](https://www.nature.com/nature/for-authors/formatting-guide)体现投稿要求对背景、图注、符号与统计说明有具体规定。本包不抄入其数字限额作为通用规则。
