# 架构

## 执行角色

根 SKILL.md 协调任务。Guide 规划、成文和修订，Audit 通读并诊断。一个 Agent 可依任务顺序执行这些角色。

从材料完成论文时，Guide 成文、Audit 审查完稿、Guide 修订确认问题。全文准备交付和重大结构重排完成后沿用该审查衔接。只读审查以诊断结束，局部写作按用户范围交付。

## 内容归属

六份标准分别负责证据、组织、语言、图表、引证和一致性。每份标准集中保存有关的判定、典型错误与例外。证据管主张成立，组织管内容位置，语言管句段表达，图表管视觉与行列，引证管来源支持，一致性管维护关系。

Guide 的六份方法按论证安排、成文修订、资料引证、图表、交付和章节任务组织。篇幅属于论证安排，章节任务提供第二导航轴。

成文目标集中在 shared/core.md。两个执行入口在开头呈现当前角色的高频行为要求，并链接共同核心。六份标准保留完整的判定、例外与示范；入口中的重点提醒用于执行时聚焦，具体判定仍归对应标准维护。

## 加载层次与时机

| 层次 | 内容与调用时机 |
| --- | --- |
| 入口重点 | Guide / Audit 开头的目标、具体行为要求和任务范围，进入角色与恢复工作时读取。 |
| 共同规则 | 每次任务启动完整读取成文核心和上下文协议，确定目标、资料复用及刷新方式。 |
| 中文成文必读 | 开始生成或改写中文正文前完整读取语言标准与成文方法，覆盖摘要、图注、表内说明和删除后的承接文字。 |
| 当前操作资料 | 按入口的加载表，在实际处理证据、组织、引证、图表、删除或投稿时完整读取匹配文件。 |
| 事件刷新 | 切换章节回读核心与入口重点；结束长篇非成文工作返回写作时重读语言标准和成文方法；新会话与上下文压缩后完整重载当前任务所需资料。 |

首次加载选中的参考文件时覆盖全文，分页和截断连续读到末尾。已经完整加载且原文仍可直接使用时，针对性回查可以定位完整章节。复用条件、资源变化与恢复事件统一由[上下文协议](../shared/protocols/context.md)维护。

Guide 和 Audit 可直接激活，各自携带完整的启动与加载要求。根入口负责角色衔接。参考文档中的关联链接按当前操作和实际判断需要使用，当前任务匹配的多条加载路径合并去重。

论文项目可以把[项目指令片段](../assets/project-AGENTS.snippet.md)放入宿主支持的项目指令位置，提供写作任务与恢复任务的入口提示。运行时由 Agent 使用宿主读取工具执行加载与接续。

## 工具与分发

scripts/lint_tex.py 与 scripts/lint_text.py 共用 language_checks.py。抽象词表从语言标准读取。操作及结果处理见[文稿工具](../shared/tooling/documents.md)。

构建器将共享标准、方法和工具复制进独立 Skill，改写并检查相对链接。安装包按文件职责保留目录；维护文档与评估材料留在源码仓库。

## 依据

Skill 格式依据 [Agent Skills 规范](https://agentskills.io/specification)。YAML 解析使用 [PyYAML](https://pyyaml.org/wiki/PyYAMLDocumentation)。仓库改动见 [CONTRIBUTING.md](../CONTRIBUTING.md)。写作质量评估见 [evals/README.md](../evals/README.md)。
