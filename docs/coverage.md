# 原始规则的归属与口径变更

以用户提供的五份文件为来源，逐个二级章节建立归属。共 69 个章节；归属记录是维护索引，不是第二份规则正文。原文件摘要与机读记录见 [coverage.json](coverage.json)。

## 关键口径调整

- 有依据的新推导、理论证明与假设可以形成；不能伪造原始观察。
- 信息推进包括有效解释、指代与衔接，不要求每句都增加新事实。
- 研究需要的背景、标准标题、必要概括、作者式引文正常保留。
- 图注不能只剩名称，须提供实际读图所需信息。
- 同值不一定同一事实；当前实现不自动覆盖论文历史快照。
- 概念清理不抹去研究历史、基线和消融对象。
- 自检清单移到审查执行方法，LaTeX 操作从规则库移到工具方法。
