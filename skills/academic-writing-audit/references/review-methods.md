# 有范围的学术审查

标准决定“何时有问题”；这里决定如何获得足以判断的证据、如何避免漏读和如何交付。

## 1. 明确审查维度

从用户请求确定局部/全文范围及结构、证据、引文、数据、视觉等维度。一般完整审查处理全部适用维度；“通读查重复”要求读全文，但不等于已核实每篇被引论文。

记录正文版本、实际读取范围和缺失资料。读完全文、核对全部引文、复算全部数据、实际看过成品分别记状态。未提供文献全文是访问缺口，不足以认定引用伪造。

## 2. 读取与索引

找到实际主入口，按章/页读取正文、摘要、必要图表、附录和脚注。TeX 的静态 input 集合仅辅助找文件；宏生成内容、外部数据与编译后的呈现仍需工具确认。PDF 中的图表要实际查看，不能只读抽取文本。

每批记录已读范围和主要主张/职责位置。全文审查不可用搜索片段、目录、摘要或状态地图替代整篇阅读。工具截断时继续读取；确实不可用则指出具体未读范围。

## 3. 逐章理解，再跨章比较

逐章回答：此章要解决什么、带来什么独有信息、使用什么依据、哪些结论在这里建立。只保留足够回查的索引，不复制整章摘要占满上下文。

读完后比较实际内容：相同主要任务是否被完整做了多次；方法、定义或设置是否不必要地散落；前提与结果是否衔接；不同地方的数值、范围、术语是否真实冲突。对每个候选回读相关原文及上下文，再确认。

必要概括与冗余的区别在功能：摘要帮助快速了解，方法使研究可理解，结果给观察，讨论给解释。相同词、相同对象、正常定义回指不够构成重复。

## 4. 核实证据与来源

检查关键结论是否有依据，强度和范围是否匹配。回查决定结论的源段、数据或推导；对照原始值重算必要指标。引文核查区分来源存在、元数据与主张支持。

没有证据访问时，报告“未核实”的具体范围，不把作者尚未给材料等同于已造假。普通风格审查不无故展开大型外部研究；需要补研究时明确哪一项能改变判断。

## 5. 检查篇幅、语言与图表

按研究任务检查背景挤占、关键论证过短、空栏目与重复总结，而非按章节长度排行判错。逐句提示应结合语境；统计词、否定句、引文作者名、对话研究材料都可以合法存在。

对确认的工程体裁泄露判断其是否在向执行者汇报而非向读者陈述；必要实现细节和作为研究对象的日志保留。图表看数据忠实性、图注及实际渲染；工具只报出它实际能确认的事项。

## 6. 问题形成与优先级

优先给会改变结论、理解或交付的诊断。一个结构根因可列多个位置，给出主要归属、移动/合并/保留建议及理由。推荐一个有依据的处理方案；事实不足时才列出会改变决策的分支，不把一切留给用户选择。

严重性不是置信度。只有实际证据支持的硬性违反才记 error；纯粹偏好不升级。现有文字符合要求时保留，不把“可写得不同”当作必须修订。

## 7. 结束与复核

只读审查交付报告后结束。联合修订任务交给 Guide；之后依据实际改动复核受影响关系。全局结构重排或用户要求时重新通读，普通语句修改不重复全篇扫描。

复核确认原问题是否消除、是否引入事实和指代回归；不要每轮加入新的轻微风格要求，让完成条件不断移动。
