# 学术文稿审查

阅读现有文稿，形成可定位的诊断。Guide 负责实际正文修订。

## 范围与加载

读取[成文核心](../../shared/core.md)与[审查方法](references/review-methods.md)。按用户指定范围选取下列材料；一般全文审查读取全部适用标准，中文语言检查完整读取语言标准。

| 检查对象 | 材料 |
| --- | --- |
| 中文句段、黑话、电报体、强调、否定与重复 | [语言](../../shared/standards/prose.md) |
| 事实、推断、计算、评价、结论范围 | [证据](../../shared/standards/evidence.md) |
| 章节职责、内容散落、篇幅、空栏目 | [组织](../../shared/standards/organization.md) |
| 图表行列、长单元格、图注与实际呈现 | [图表](../../shared/standards/visuals.md)，中文部分使用语言标准 |
| 引文、来源支持、引用系统与声明 | [引证](../../shared/standards/citations.md) |
| 重复维护、删除残留与失效引用 | [一致性](../../shared/standards/consistency.md) |
| 跨章及恢复任务 | [上下文协议](../../shared/protocols/context.md) |
| 文稿读取、工具结果和成品 | [文稿工具](../../shared/tooling/documents.md)；TeX 另读[LaTeX 操作](../../shared/tooling/latex.md) |

全文任务逐章通读正文、摘要、必要图表、脚注与附录，记录实际范围。局部任务读取指定位置及判断所需的上下文。文件读取遇到截断时接续到末尾。

## 判定与交付

先理解各章，再比较主张与职责。对重复、冲突和否定尾句回读相关原文，根据标准中的具体判定和例外形成结论。

每个确认问题包含位置、必要原文、影响、标准 ID 和推荐处理。跨章问题列出关联位置并确定主要归属，同一根因合并报告。

- `error`：已确认的事实、来源、数据、授权或硬性提交要求违反。
- `warn`：需要修正的表达或结构问题，包括无意义免责、黑话、电报体、畸形表格和删除残留。
- `info`：可选改善。

材料缺口以具体待核实事项列出。报告先交代阅读范围，再给重要诊断。只读请求以报告交付为结束点；检查并修改的请求把确认问题交给 Guide，完成修订后核对受影响内容。
