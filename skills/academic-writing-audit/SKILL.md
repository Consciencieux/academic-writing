# 学术写作审查

本 Skill 负责检查**已经存在的文稿**。审查的判定标准来自共享规则；此处仅规定检查范围、工作顺序及输出约定。正向起草和日常改写由 `academic-writing-guide` 负责。

## 1. 选择审查范围

| 模式 | 触发场景 | 必须处理的内容 |
| --- | --- | --- |
| 局部审查 | 用户指定某段、某节或某一种问题 | 指定范围及判断所必需的周边语境 |
| 全文审查 | 用户说“通读全文”“整体检查”“投稿前检查”“查跨章节重复/职责冲突/篇幅分配”等，或明确交付整篇论文供审查 | 全部可访问的正文、章节、必要图表/附录，以及支撑跨章节判断的证据来源 |

**全文审查不能退化为目录扫描、抽样阅读或只看摘要。** 长文可分批读取，但必须记录覆盖范围并在跨章节比较前确认所有必要部分已经读取。若文件缺失、内容无法解析或工具截断，应报告未覆盖范围，并把结论限制在已读内容，不宣称全文审查完成。

完整操作见 [全文审查方法](references/full-document-audit.md)。用户只需一般局部审查时不必执行全部步骤。

## 2. 查找和加载规则

源代码布局中规则位于本 Skill 目录的 `../../shared/rules/`；独立发布包中位于 `references/rules/`。**优先使用实际存在的目录并读取适用文件**，不能因为 `SKILL.md` 写了链接就认为文件已加载。

- 所有审查：`content-and-judgment.md`、`language.md` 和 `self-check.md`。
- 全文结构、篇幅、图表、章节分工：另读 `structure-and-formatting.md`。
- 跨文件事实、术语、概念清理：另读 `ssot-and-concept-cleanup.md`。
- 涉及 LaTeX 排版或代码：另读 `latex-mechanics.md`，并执行可用的机械检查。

LaTeX 机械检查脚本：源代码布局 `../../scripts/lint_tex.py`，独立发布包 `scripts/lint_tex.py`。按实际存在的路径使用，不得假定运行成功。对于 Markdown、DOCX、PDF 或其他格式，使用适用工具读取实际内容；LaTeX lint 不代替语义审查。无法访问必需的规则或工具时，应在结果中说明。

## 3. 工作流

1. **确定覆盖**：识别当前任务的文稿入口、章节与相关文件；全文审查先建立完整阅读清单。
2. **机械检查**：对适用的 LaTeX 项目运行 lint，记录输出。错误、警告与信息提示须结合具体语境判断；正则命中不等于语义问题已成立。
3. **内容与证据**：核对事实来源、判断强度、时间及统计口径、因果与相关、设计目标与已验证结果。
4. **结构与语义**：局部审查处理段落任务和语义重复；全文审查进一步建立章节职责图，比较章节间的论点归属、重复、冲突与篇幅分配。
5. **文体与材料**：检查模板腔、抽象词堆叠、元话语、过程播报，以及把工程记录、聊天往返和任务指令混入论文正文的现象。
6. **判定与交付**：按下列约定报告；用户明确要求修改时，先根据问题对内容重组，再复查受影响范围。

## 4. 问题报告约定

每条确认的问题包含：**位置**（文件与行号，或章节标题与段落）、**原文证据**（必要的短片段）、**具体问题**、**判定依据**（`shared/rules/<file>.md §n` 或 lint 编号）、**建议处理**。涉及两个以上章节时同时列出对应位置，并给出明确的内容归属建议。

| 等级 | 判定含义 | 典型情况 |
| --- | --- | --- |
| `error` | 明确违反硬性要求或关键事实规则 | 虚构数据或来源、将未知写成确定、证据不足的强因果、重复维护造成事实不一致 |
| `warn` | 有具体证据的明显质量或结构问题 | 章节职责冲突、重复论证、关键内容分散、篇幅与信息不匹配、材料泄露、模板化表达 |
| `info` | 可选择的改进空间 | 在当前语境中不影响结论的措辞或呈现优化 |

不把主观偏好、正常的专业术语、摘要的必要概括或公式/定义的必要重复标成硬性问题。只有充分证据支持时才使用 `error`。同一根因的多个位置可以在一条问题里联合列举，避免把同一个结构问题拆成大量机械重复的报告项。

## 5. 报告还是修改

- **用户只要求审查**：仅输出问题及建议，不修改文件。
- **用户要求修订**：按照证据和章节任务实际重组内容，必要时合并、移动或删除段落；随后复查改动涉及的语义关系及引用。
- **依据不足或存在多种合理处理方式**：说明缺口及候选安排，不擅自发明事实或新研究主张。
- **没有发现问题**：说明实际检查范围和检查方式；不要把“未发现”表述成绝对无误。

全文审查报告开头必须写明**覆盖情况**（已读、未读、无法读取的范围）。只报告对论文理解、证据或表达有影响的事项，不为凑清单制造问题。
