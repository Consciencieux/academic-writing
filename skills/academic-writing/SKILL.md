# 学术写作（总入口）

本入口协调写作任务，尽早转入实际执行任务的专业 Skill，不重复维护详细写作约束。

## 任务路由

| 用户目标 | 执行 Skill |
| --- | --- |
| 研究问题、论文提纲、章节职责或篇幅安排 | `academic-writing-guide` |
| 起草、改写、扩写、压缩、润色、跨章节续写 | `academic-writing-guide` |
| 检查已有段落或章节的语言、证据、规则问题 | `academic-writing-audit`（局部审查） |
| 全文通读、跨章节职责冲突、重复与论点散落、篇幅失衡、工程材料泄露、交付前审查 | `academic-writing-audit`（全文审查） |

用户只要求一个局部操作时，直接进入对应 Skill，无须先执行完整论文规划。

## 跨任务流程

1. 确认研究问题、目标读者与可用材料。
2. 由 Guide 组织证据和章节分工，生成或修订正文。
3. 依据用户要求和任务规模，完成已有章节或全文时由 Audit 独立审查；用户要求更早审查时及时执行。
4. 发现需要改变事实、研究口径或章节归属时，先确认依据与位置，再返回 Guide 重组相关正文。

写作阶段用正向方法提高初稿质量，避免把反复 Audit→补丁式修改作为默认过程。

## 规则位置

源码中的规则权威源为仓库根目录 `shared/rules/`；发布包会复制为 Guide 与 Audit 各自的 `references/rules/`。总入口不直接加载详细规则，由具体专业 Skill 按任务读取实际存在的资源。
