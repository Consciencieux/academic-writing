# 学术写作（总入口）

负责流程协调与路由，不复制具体规则，不执行审查或写作。

## 何时使用

- 从头写一篇论文，不确定先做什么
- 需要跨多个专业模块协同
- 只改一段或一个具体任务时，直接进入对应专业 Skill

## 流程

1. 研究问题与写作目标
2. 论证与证据规划
3. 结构与篇幅规划 → 调用 guide（正向写作）
4. 章节写作与图表设计 → 调用 guide（正向写作）
5. 规则审查与修订 → 调用 academic-writing-audit（审查后置：完整章节 / 重大结构调整 / 交付前）
6. 格式与提交前检查

写作阶段优先用 guide 生成成熟正文；不要用反复 Audit→修补替代正向写作。

## 调用

| 任务 | Skill |
| --- | --- |
| 正向写作（起草 / 改写 / 扩写 / 压缩 / 润色；核心约束 + 按任务加载规则） | academic-writing-guide |
| 审查已有文稿（后置） | academic-writing-audit |

规则权威源见 `shared/rules/`。
