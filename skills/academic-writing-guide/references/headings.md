# 论文题名与章节命名

拟论文题名、编排目录或改写章节标题时，读取[组织标准](../../../shared/standards/organization.md)和[语言标准](../../../shared/standards/prose.md)。标题中的发现、比较和贡献使用[证据标准](../../../shared/standards/evidence.md)。从实际研究形成名称，不为规避某个禁用句式连续改换外壳。

## 从研究内容确定命名对象

主标题依据研究问题、实际工作和正文支持的结果确定；小标题依据本节内容、上级范围及相邻章节职责确定。提纲阶段可以依据已确认的研究安排使用暂定名称，成文后对照实际内容调整。只有宽泛主题时，题名保持相称的范围，不替研究补造方法或发现。

先弄清当前研究或章节最重要的对象及关系。方法章介绍了输入、步骤、参数和复杂度，不必把四项全放进标题；它们可以共同解释一个具体算法。结果节包含多个指标时，先确定本节围绕什么比较，再保留区分这项比较的必要信息。

## 形成论文题名

根据文种选择需要被读者识别的信息：经验研究突出对象、变量关系或比较问题；理论研究突出问题或命题；系统研究突出实际解决的技术问题；综述突出材料范围与综述对象。使用领域中准确、常见的名称，选择自然的中文搭配。必要的方法、地区、样本、工况或研究设计应保留到足以辨认研究的程度。

主标题先完整表达研究重心，副标题只在确需补充范围、对象或文种时使用。不要先写一个宽泛主题，再把所有贡献或关键词列在冒号后。正文是探索、设计或局部验证时，题名保持相应状态；已经充分建立的发现可以直接命名，避免把明确判断一律降为模糊话题。

## 形成章节与小节名称

以章节承担的任务命名。按模板保留引言、方法、结果、讨论和结论；具体小节用明确对象区分方法步骤、实验条件、结果比较或推导关系。上级已明确对象时，下级省去重复背景，同时保留区分兄弟小节的信息。

实际并列的设置使用相称名称，如“启用缓存”和“禁用缓存”。不因句法相似而制造词语变化，也不把不同职责强行套成同一骨架。确实需要回答一个研究问题时可以用问题型标题，不给普通定义、设置和结果逐一加提问。

## 取舍信息与自然成句

保留主对象、决定含义的关系及必要范围，删去重复概括、评价性装饰和可在正文展开的细节。不要为了准确而将所有关键词塞进标题，也不要为了短而省略决定研究性质的词。专业长名称正常保留，不创造未经定义的缩写。

小标题的字数参考按[ORG-04](../../../shared/standards/organization.md#org-04)使用：4–12 字可优先尝试，13–18 字可正常使用，超过 18 字回看内容取舍；“引言”“方法”等无需凑长。论文题名依据实际研究和目标要求安排，不套用小标题参考。完成命名与定位即停止，无须额外追求对仗、独特或记忆点。

## 根据材料拟题的示例

以下为合成教学材料。示例展示内容取舍，不是可轮流套用的题名模板，也不提供被禁修辞的正面示范。

| 研究或章节实际内容 | 可用题名或标题 | 保留的重心 |
| --- | --- | --- |
| 课程报告在同一输入规模与配置下比较两种队列调度策略的处理延迟 | 固定负载下两种队列调度策略的延迟比较 | 研究对象、比较指标与必要条件，未预告普遍优势 |
| 方法章的一节说明模型边界条件和参数设置 | 模型设置 | 内容由上级限定，不把设置过程写成授课提问 |
| 一节用数值仿真比较不同点火时刻对应的缸内压力变化 | 点火时刻对缸内压力的影响 | 实际自变量与响应量；计算方法由方法章交代 |
| 本节定义请求入队至计算完成的处理时间，并区分网络传输项 | 处理时间的定义 | 准确命名定义任务，具体排除项进入正文 |
| 本节说明利用仿真比较并选择发动机参数组合 | 发动机参数的仿真筛选 | 对象与方法关系清楚；只做比较时应相应改为比较名称 |
| 综述整理动态图上最短路径算法，比较其更新策略和适用条件 | 动态图最短路径算法综述 | 文种与对象明确，具体比较维度留在正文 |
| 理论章节给出唯一性定理并展开证明 | 解的唯一性 | 命名所证明的性质，不添加重要性或突破评价 |
| 实验的两个小节分别固定其他配置，比较缓存开、关时的记录 | 启用缓存；禁用缓存 | 真实并列设置使用平行名称，无须强制差异化 |

## 改题与完成

审核反馈只说明需要修复的缺陷，实际改名仍回到研究内容。发现冒号堆词时重新确定核心研究，发现讲解式标题时直接命名对象，发现别扭搭配时恢复明确的动作或修饰关系；不能仅换标点、删除疑问词或换一组抽象词。

只改标题时，正文继续作为依据并保持不变。按授权同步目录、明确写出的章节名、题名宏及相关元数据；现有稳定引用标识没有失效时沿用。发现章节重心不成立或证据不足，报告具体位置，不能为维护拟定标题重写研究。

将题名与正文、目录及目标格式对照。确认研究范围没有扩张、术语自然、层级协调、必要限定保留后交付。仅获题名片段时，按可见内容说明具体局限，不宣称已审查全文。
