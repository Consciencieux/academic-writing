# 学术写作指南

正向写作方法与始终生效的精简核心约束。详细规范与权威判定见 `shared/rules/`；独立审查由 `academic-writing-audit` 负责。

## 写作方法

生成或修改学术正文时，执行以下原则：

1. 先明确当前章节要回答的问题，以及本段需要建立的事实、判断或论证关系。
2. 根据可用证据形成主张。每个重要判断的强度与证据一致，不补造材料中不存在的事实。
3. 组织自然、完整的学术陈述。后续句子应推进信息，而非换词重述已有结论。
4. 段落围绕实际内容展开；章节各自承担明确任务，篇幅由信息量和论证需要决定。
5. 将工程记录、交流材料和过程日志转化为研究事实或方法描述，再以论文读者视角组织正文。
6. 保持既有术语、指标、事实来源与全文论证的一致性。

## 规则加载

开始写作前，依据任务范围读取相关权威规则（不要每写一段就重读全部规则；持续生成靠上文核心契约）：

- 内容与证据：`shared/rules/content-and-judgment.md`
- 语言表达：`shared/rules/language.md`
- 长文及章节写作：`shared/rules/structure-and-formatting.md`
- 跨文档事实一致性：`shared/rules/ssot-and-concept-cleanup.md`

规则应从实际安装位置解析。具体条文以共享文件为准；本 Skill 不复制规则正文。

虚构实验数据、编造参考文献、改变原始事实、把相关性写成因果等硬底线，以 `shared/rules/content-and-judgment.md` 等为准；写作时只强调判断强度与证据一致、不补造。

## 写作质量

优先交付内容与表达已经成熟的正文。可以在生成过程中调整论证和句式，无须输出内部检查过程。

全文完成、完整章节写定、重大结构调整或交付前，再调用 `academic-writing-audit` 做独立审查。不要用反复 Audit→修补替代正向写作。

## 待建设

以下另开工作补充，本 Skill 当前只立契约入口：

1. 引言、相关工作、方法、结果、讨论等章节的正向写作方法
2. 少量高质量正文范例（体现信息推进与自然表达，避免填空模板）
3. 从研究问题到主张-证据映射、从提纲到初稿的细步骤

不要把 audit 的禁止事项清单反向粘贴成本文的指导。
